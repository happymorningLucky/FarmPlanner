การแสดงผล มี 6 ส่วนหลัก คือ
1. ระบบล็อกอิน : 
   - มีหน้า Login ผู้ใช้ที่ล็อกอินแล้วเท่านั้นจึงจะเข้าถึงระบบจัดการได้
       - แอดมินเท่านั้นที่สามารถเพิ่มผู้ใช้ได้
       - ผู้ใช้ทุกคนสามารถแก้ไขรหัสผ่านของตัวเองได้
       - ถ้าแอดมินลืมรหัสผ่านให้ส่งเมล์ไปที่อีเมล์ที่ตั้งค่าไว้
2. หน้า planner
     - แสดงคำเตือนของเดือนนั้นในรูปแบบ การ์ด เอาข้อมูลมาจากหน้าปัญหาเฝ้าระวัง
     - แสดงพิกัดแปลง 
   - แสดงปฏิทินรายเดือนและงานที่มีในแต่ละวัน
   - คลิกที่วันเพื่อสร้าง task ใหม่ หรือคลิกที่งานเพื่อแก้ไข
   - การเพิ่ม แก้ไข task :
     - ข้อมูลที่ต้องกรอก: วันที่, ชื่องาน, แปลง, สถานะ, ไอคอน, สี
     - ถ้าชื่อ task มีคำว่า "พ่น" ให้แสดงช่องกรอก "จำนวนถังที่ใช้ (200L/ถัง)" ถ้าชื่องานมีคำว่า "ใส่" ให้แสดงช่อง "จำนวนต้น:" 
     - สามารถเลือกพัสดุหลายรายการเพื่อใช้ในงานนี้ได้
     - ระบบแจ้งเตือน: ถ้าระบุปริมาณพัสดุที่ต้องใช้ "มากกว่า" สต๊อกที่มีอยู่จริง ให้แสดงคำเตือน "⚠️ สต๊อกไม่พอ ขาดอีก..." ทันที
     - ระบบหักสต๊อกอัตโนมัติ: เมื่อเปลี่ยนสถานะ task เป็น "เสร็จสิ้น (ACTIVATED)" ให้ระบบไปหักลบจำนวนพัสดุในฐานข้อมูลสต๊อกทันที และถ้าเปลี่ยนสถานะกลับเป็น "รอดำเนินการ (WAITING)" ให้คืนยอดสต๊อกกลับมา

     -ถ้าทำ task ไม่เสร็จในวัน หลังเวลาที่กำหนด จะมี alert เตือนเฉพาะเข้าครั้งแรกของวันเมื่อเลยวันมาแล้ว และเปลี่ยนสี task เป็นสีส้ม ถ้าเลื่อนวันก็แก้ไขไปวันที่เลื่อน แล้ว มี* ว่าเลื่อนจากวันเดิมมาอีกกี่วัน

     - ช่องของปฏิทิน จะมีข้อมูล อุณหภูมิ ความชื้นเฉลี่ย และพยากรณ์ฝน ของทุกวัน ย้อนหลัง 14 วัน และ เดินหน้า 14 วัน เอาข้อมูลมาจาก API เป็นข้อมูลของพิกัดแปลงที่ผู้ใช้กำหนด


3. หน้า Dash board ภาพรวม 

หน้านี้ admin สามารถเข้าไปดู dash board ได้คนเดียว มี 4 ส่วน ส่วนแรกแสดงค่าที่รับค่ามาจากอุปกรณ์ IoT update แบบ realtime  VPD, ค่า EC น้ำ ดิน และ NPK （ให้สร้างเป็น mockup ไว้ก่อน รองรับการเชื่อมต่อในภายหลัง）ส่วนที่ 2 แสดงค่าพยกรณ์อากาศล่วงหน้า 7 วัน ดึงค่ามาจาก API
ส่วนที่ 3 เพื่อแสดงสต๊อก ปุ๋ยและสารเคมี เมื่อคนงานสร้าง task พ่นยา ก็ไปหักปริมาณยาที่ดึงมาจากหน้าแดชบอร์ดนี้, ปริมาณปุ๋ยในสต๊อก ที่ลิ้งค์กับการปฏิบัติงาน เมื่อคนงานสร้าง task ใส่ปุ๋ย แล้ว activated task ก็ไปหักปริมาณปุ๋ย
-สามารถ update สต๊อกสารเคมี และ ปุ๋ย เพิ่ม สามารถเพิ่มชนิดเองได้ ให้เป็น แบบ SPA 
ส่วนที่ 4 เป็นส่วนของผู้ใช้งาน สามารถเพิ่ม ลบ ได้ตรงส่วนนี้

- สามารถค้นหาด้วย เดือน,แปลง,สาร หรือกิจกรรมได้

เพื่อรวบรวมปัญหาและแนวทางปฏิบัติในแต่ละเดือน (นำไปแสดงเตือนบนปฏิทิน) สำหรับจัดการ Issue โดยใช้ภาษาไทยทั้งหมด
- มีให้เลือกช่วงเดือน และนำข้อมูลในแต่ละ task ในช่วงเดือนนั้นไปโชว์ในรูปแบบการ์ด บนหน้า planner บนปฏิทิน
- ประกอบกด้วย เดือน,ปัญหา,วิธีแก้ไข,ผู้รับผิดชอบ โดยสามารถ สร้าง แก้ไข ลบ task ได้
- มีปุ่ม ปิดปัญหา เมื่อปัญหาได้รับการแก้ไข และจะย้ายไปอยู่หน้า ปัญหาที่ได้รับการแก้ไข
